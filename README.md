# Hungry Giraffe

A React-TypeScript recreation of the classic Casio Hungry Giraffe handheld game.

## About the Game

Hungry Giraffe is a classic arcade-style game from the 1980s where a giraffe character must eat leaves while avoiding obstacles. The goal is to achieve the highest score possible while managing the giraffe's health and movement.

## Tech Stack

- **React 18** - UI library
- **TypeScript** - Type-safe JavaScript
- **Vite** - Fast build tool and dev server
- **CSS** - Styling

## Getting Started

### Installation

```bash
npm install
```

### Development

Run the development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to see the game.

### Build

Create an optimized production build:

```bash
npm run build
```

### Preview

Preview the production build locally:

```bash
npm run preview
```
