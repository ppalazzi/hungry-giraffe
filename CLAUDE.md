## Project Overview

**Hungry Giraffe** is a React + TypeScript web application built with Vite. It's a modern frontend project with strict TypeScript checking and ESLint enforcement.

## Common Development Commands

```bash
npm run dev      # Start Vite dev server (http://localhost:5173)
npm run build    # Type-check and build for production (output: dist/)
npm run lint     # Run ESLint with strict no-warnings policy
npm run preview  # Preview the production build locally
```

## Code Architecture

### Directory Structure
- **`src/`** - Source code
  - `main.tsx` - Entry point, mounts React app to `#root` element
  - `App.tsx` - Root component
  - `index.css` - Global styles
  - `assets/` - Static assets (images, etc.)
- **`index.html`** - HTML entry point with `<div id="root">` mount point
- **`vite.config.ts`** - Vite configuration with React plugin
- **`tsconfig.json`** - TypeScript configuration
- **`.eslintrc.cjs`** - ESLint configuration
- **`dist/`** - Production build output (generated by `npm run build`)

### Key Technologies & Constraints

- **React 18** with Strict Mode enabled
- **TypeScript 5** with strict mode (`strict: true`)
- **Vite 4** for fast development and optimized builds
- **No testing framework** - tests should be added as needed
- **No state management library** - use React Context or local state as appropriate

### TypeScript Configuration

The project enforces:
- `noUnusedLocals: true` - must declare and use all variables
- `noUnusedParameters: true` - must declare and use all parameters
- `noFallthroughCasesInSwitch: true` - switch statements must have explicit cases
- `jsx: "react-jsx"` - modern React 18 JSX transform (no need to import React)

### ESLint Rules

- Extends `eslint:recommended`, `plugin:@typescript-eslint/recommended`, and `plugin:react-hooks/recommended`
- `react-refresh/only-export-components` rule enforces that non-component exports should be moved out of files with components (warn level with constant export exceptions allowed)
- Build will fail if lint has any warnings (`--max-warnings 0`)

## Game Design

See [`docs/GAME_SPEC.md`](docs/GAME_SPEC.md) for the full gameplay spec —
segment-grid layout, the neck extension axis, the coconut hazard, the Phase 2
jump mode, and the LCD clock.

The spec was rewritten against the CG-91 specification in HG-23, which
superseded the original design. Commits before that rework (HG-9 through HG-12)
implemented a different game: equal vertical lanes, an explicit eat button, and
a monkey that moved between branches and blocked eats. Read the spec, not those
commits, for current behaviour.

## Development Notes

- **Hot Module Replacement (HMR)** is enabled by default - changes in `src/` will reflect immediately in the browser
- The build process runs TypeScript type-checking first (`tsc`) before bundling
- Production builds are optimized for performance; use `npm run preview` to test production-like behavior locally
- The project uses ES modules (`"type": "module"` in package.json)
